# Contributing to Awesome Local Web AI

Thank you for your interest! Please follow these guidelines to keep the list high-quality and useful.

## ✅ What to Add
- Frameworks, libraries, or tools for **client-side web AI** (LLMs, vision, audio, agents)
- Browser-optimized models (GGUF, ONNX, MLC) with clear usage notes
- Demos, tutorials, or benchmarks that work in modern browsers (Chrome, Edge, Firefox, Safari)
- Standards or APIs directly related to WebGPU, WebNN, WASM, or browser caching

## ❌ What Not to Add
- Cloud-only or server-dependent inference tools
- Projects without recent activity (>12 months) or broken documentation
- Paid/closed-source tools without a free tier for developers
- Duplicates or vague "AI in general" resources

## 📝 Format
Use this markdown structure:
- [Name](URL) – Short description (max 1 sentence). Focus on browser relevance.

## 🚀 How to Submit
1. Fork the repo
2. Add your link in the appropriate category
3. Commit with a clear message: `Add: [Tool/Model Name]`
4. Open a Pull Request

PRs are reviewed within 3–7 days. Thank you for helping the community! 🌐🧠
